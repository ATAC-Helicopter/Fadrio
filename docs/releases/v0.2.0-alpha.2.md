# Fadrio 0.2.0 Alpha 2

This source-only alpha completes adoption of the final Fadrio identity. It contains the application-centric PipeWire mixer foundation under the supplied Fadrio branding.

## Highlights

- Renames all managed projects, namespaces, binaries, native library and C ABI symbols to Fadrio.
- Adopts `dev.fglabs.Fadrio`, Fadrio XDG paths, `fadrio`, and `fadrioctl` before those identities become stable public contracts.
- Replaces the former artwork with the supplied dark/light banners, logos, symbols, and application icons.
- Renames current repository, tracker, documentation, release, and website surfaces while preserving stable GitHub issue numbers and release tags.

## Important limitations

- This remains a source-only evaluation snapshot with no supported binary package.
- Persistence, the finished mixer UI, tray integration, MIDI control, profiles, and localization are not implemented yet.
- Existing Alpha 1 source archives retain their historical contents; Alpha 2 is the first source archive containing the complete Fadrio identity.
